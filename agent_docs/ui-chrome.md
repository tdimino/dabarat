## Client UI chrome and interaction conventions

How the client surfaces behave: home rail and cards, floating buttons, panels, menus, dialogs, TOC, editor, and the keyboard/focus contracts they share. Module layout and the render pipeline are in `client-architecture.md`; animation call sites in `motion-one.md`; workspaces in `workspace-system.md`. Read this before changing anything in `dabarat/static/js/` or `dabarat/static/palette.js` that a user can see or focus.

### Keyboard, focus, and delegation

- **Event delegation**: Never use inline `onclick` handlers in dynamically-built HTML—use `data-*` attributes + `addEventListener` event delegation. This prevents XSS via HTML entity decoding in path strings.
- **Menu keyboard model**: `_menuKeyNav(menu, itemSelector)` in `tabs.js` gives the `.tab-context-menu` family `role="menu"` + `menuitem` rows (`tabindex="-1"`) with ArrowUp/Down traversal and Enter activation; the context menu focuses its first row on open. The instance dropdown is `role="dialog"` instead—its rows hold real buttons, so Tab traverses natively. Any new dropdown reuses `_menuKeyNav`, and any hover-revealed control (overflow close ×, float-button labels, home ghosts) must pair a `:focus-within`/`:focus-visible` reveal so keyboard focus is never invisible.
- **Dialogs and focus**: `openDialog(el, {modal, initialFocus, returnTo})` in `utils.js` backs the palette and the lightbox; the frontmatter popup and the instance menu implement the same contract by hand (focus in on open, back to the opener on dismiss, Tab trapped when modal). The tab strip is a `role="tablist"` of `<div role="tab">` elements with roving tabindex (ArrowLeft/Right, Home/End move focus without activating; Enter/Space activate; Delete/Backspace close the focused tab; `aria-selected`/`aria-controls`) and separate close buttons; the instance menu is non-modal and returns focus to the indicator on Escape/close-button but deliberately NOT on an outside click (the click's target takes focus); `#main-area`/`#content` are `<main>`/`<article>`, the annotation gutter is `<aside>`, the theme toggle has an accessible name.
- **Status banners**: one factory — `_showStatusBanner(id, message, severity, {actions, icon, timeout, dismiss})` in `tabs.js` — sets `role="status"` + `aria-live="polite"` (or `role="alert"` + `assertive` for `error`) and `data-severity="info|warn|error"` (blue / yellow / red per the attention-hue convention). `home.js` and `editor.js` never hand-build a `.status-banner`. Server-side signals that surface through it: `snapshotFailed` on `/api/content` (external change not versioned — reported once per failure, then cleared; rides along on the `since=` short form too) and `corruptBackup` on `/api/annotations` (sidecar quarantined).
- **Motion One**: Optional animation CDN loaded as ES module (`@motionone/dom`). Assigns `window.Motion` with `animate`, `stagger`, `spring`. All call sites MUST guard with `if (window.Motion && !_prefersReducedMotion)` for progressive enhancement + accessibility. `_prefersReducedMotion` is a `let` in `state.js` kept live by a `matchMedia('(prefers-reduced-motion: reduce)')` change listener. Falls back to CSS `@keyframes` animations. See `motion-one.md` for full call site reference.
- **localStorage prefix**: `dabarat-*` keys. Migration IIFE in `state.js` copies `mdpreview-*` → `dabarat-*` on first load.

### Floating buttons, gutter, and panels

- **Floating button hover pattern**: `#annotations-toggle`, `#edit-toggle`, `#history-toggle`, `#justify-toggle`, and `#toc-restore` use halo-glow hover (accent border + ring shadow + diffuse glow + `scale(1.08)`) rather than solid background fill. All are glassmorphic circles with `backdrop-filter: blur(8px)` behind `@supports`; `scale(0.96)` active state for tactile feedback. The four right-edge buttons live in `#float-column` (history-ui.css, 2026-09-07): one fixed flex column at `top: 46px; right: 14px` with a 6px gap, so a hidden button drops out of the ladder instead of leaving a gap (per-button `top` offsets once put History and Justify on the same 126px below 1400px). `body.gutter-visible` steps the column to `right: 294px`, beside the annotations gutter, never on its header; `body.diff-mode` and `body.edit-mode` hide the column, `body.version-panel-open` fades it. All four carry expand-on-hover `.float-btn-label` pills (Edit / History / Notes / Justify) — shared CSS at the END of `history-ui.css` so it wins cascade ties.
- **Annotations gutter dismissal**: over 1400px the gutter is a native column, under it an overlay — both close. The header × (`.ann-gutter-close`, always painted) calls `dismissGutter()`: on wide widths it sets `html.gutter-hidden` (localStorage `dabarat-gutter-hidden`, pre-applied by the FOUC script so the column doesn't flash), zeroes `#main-area`/`#tab-bar-wrapper` right margins, and the Notes float returns to reopen it; on narrow widths it closes the overlay. `syncGutterLayout()` (annotations.js) derives `body.gutter-visible` and the toggle's `.gutter-native` from the gutter's computed display — a MutationObserver on the gutter's `style`/`class` plus the 1401px matchMedia listener cover every inline hide (home/edit/diff) without touching those modules. `toggleGutter()` / `revealGutter()` are the only entry points (Notes float, palette "Toggle Annotations", "Show Variables", the annotate carousel) — never branch on `innerWidth` at a call site.
- **Compare view exit**: `body.diff-mode` (set/cleared in `diff.js`) hides the float column; the exit is a labelled `.btn` in `.diff-header` ("Exit compare" + `kbd` Esc), not a ghost × — the × at the far right read as decoration and sat under the floats.
- **Version history panel**: UI: palette command "Version History", `Cmd+Shift+H`, floating `#history-toggle` button. Timeline has day separators, source badges, pin/label actions, count badge, delegated event handling. `enterVersionDiffMode` in `diff.js` diffs against the historical version. Panel identity: header shows a mode icon (`ph-clock-counter-clockwise` file / `ph-pulse` Activity) + `#version-panel-filename`; global rows carry a dimmed parent-dir suffix. Change excerpts: per-row caret expander lazily fetches `GET /api/version/summary` (`history.version_change_summary()` — first-hunk changed lines vs predecessor, 5000-line cap); client caches successes only on `_versionsByRef` (`'loading'` sentinel, delete-on-failure keeps retries possible, `entry.isConnected` guard after await). Version-timeline rows hover with `--interactive-muted-bg` (tint), not `--ctp-surface0` (cold slab on Vellum); `.version-btn` sits on `--card-bg` at subtext tier. Regression: `python3 scripts/verify/phase13_history_clarity.py` (V1–V6: excerpt contract, error codes, panel wiring).
- **Frontmatter modal**: `.fm-popup-backdrop` is `align-items: center` (true centre, never top-anchored). Fields without a dedicated renderer go through `_fmFieldGrid()` (`frontmatter.js`) — a `<dl class="fm-popup-fields">` grid: keys in `--hljs-keyword`, string values in `--ctp-text`, numbers/booleans in `--hljs-number`, URLs as links in `--hljs-function`, scalar arrays as `.pmc-label` pills, plain objects as a nested inset grid (depth ≤ 2, keys in `--hljs-params`), anything else as `.fm-popup-raw` JSON. textContent only — never innerHTML with frontmatter values. `.prompt.md` files auto-detect YAML frontmatter → indicator bar + click-to-open metadata popup. `{{variable}}` and `${variable}` template slots highlighted as colored pills with schema tooltips.
- **Image lightbox**: Content images (excluding `.emoji` and `.tpl-var-img`) get `cursor: zoom-in` and open lightbox on click.
- **Emoji style**: 4 options (Twemoji, OpenMoji, Noto, Native) via `EMOJI_CDNS` in `theme.js`. `applyEmojiStyle()` runs after `marked.parse()`.

### Home rail and cards

- **Home rail and cards** (critique pass, 2026-09-07 — `.design-critique/20260906-200000__home-page.md`, local): `_effectiveHomeView()` in `home.js` is the single source for which list the rail shows — with no folder chosen every dispatch falls to Recent, so the Files/Recent segmented control (`aria-pressed`), the rail label ("Recent" / "Workspace" / workspace name), and the dispatch all derive from it; never set `.active` from the requested mode. With no folder the path line is a real button reading "Choose a folder…" with the pencil visible. Recent rows are a 6px hue dot (the file kind's accent from `_fileBadges[].hue`, hollow overlay0 ring when unbadged) + a name that may wrap to two lines + the time in its own right column — no MD glyph, no badge chip (the chip repeated the same word down the rail and left the name ~95px to truncate in). Files/browse rows keep their folder/file icons. Rows are inset 6px with `--radius-sm` and hover on `--interactive-muted-bg` (raw surface0 floated above Vellum's rail). The card's 2px top strip takes the same `hue`, else `--home-title`, so one file kind is one colour on rail, badge, and strip and an unbadged card agrees with the page's pigment (the old per-extension map made every `.md` blue). Card titles clamp at two lines and `.home-grid` stretches rows; the hero grows to its excerpt (`max-height`, never a 160px reservation) and holds its text to `--measure`; the preview fade paints only on `.overflowing` (set by `_markPreviewOverflow` after every render). Home metadata has a 10.5px floor (10.5 / 12 / 13 / 15 / title); icons may be smaller. Keyboard: `rovingList(container, selector, opts)` in `utils.js` gives the three rail renderers `listbox`/`option` rows and the card grid a roving tab stop (Arrow/Home/End, Enter/Space → click, re-seedable after re-render); hover-revealed remove buttons also reveal on `:focus-within`. Under 900px the rail is not forced off-canvas on home — `.toc-collapsed` plus the overlay rules own that, so `#toc-restore` works. Day groups label by the key that sorts them (`lastOpened`), never `mtime`.
- **Workspace system**: See `workspace-system.md` for full internals. Key state: server-side `_active_workspace`/`_active_workspace_path`, client-side in `state.js`.

### TOC

- **TOC navigation**: JS-driven, never native hash navigation (browsers only scroll on hash *change* — same-hash re-clicks would be silent no-ops). Delegated click handler on `#toc-list` (rebound by `_tocBoundList` node identity since home mode destroys/restores the node), generation-counted jumps (`_tocActiveJump`), `history.replaceState` hash sync with `{targetId, tabId}` ownership, stale-hash clearing on tab switch, jump re-resolution across polling re-renders. `--toc-heading-offset` (typography.css, 80px on `#content`) is the single source for the JS jump offset, heading `scroll-margin-top`, and the scroll-spy threshold (+2px landing epsilon). `scrollIntoView` is BANNED in render.js — it can cancel the window's in-flight smooth scroll; sidebar centering uses `centerTocLink()` (`#toc-scroll.scrollTo` only). Regression: `python3 scripts/verify/phase7_toc_navigation.py` (V1–V20 CDP matrix), `phase8_editor_roundtrip.py` (V1–V9 link/image/footnote round-trip), `phase9_save_path.py` (V1–V8 save-path integrity), `phase10_sqlite_store.py` (V1–V10 store semantics + git import). ExecPlan: `toc-navigation-execplan.md`.
- **TOC sidebar toggle**: `Cmd+\` keyboard shortcut (also in command palette). Collapse state persists to `localStorage` key `dabarat-toc-collapsed`. `#toc-restore` button bounces in with spring animation (`tocRestoreBounce` keyframe, optional Motion One spring override). JS `matchMedia` listener at 900px fires `toggleToc()` for smooth CSS transitions instead of hard media-query snap; auto-collapse does NOT persist to localStorage (preserves user intent). Content auto-centers when TOC is collapsed (`#content { margin: auto }` globally, `#main-area` margins zeroed).

### Editor

- **WYSIWYG editing**: Tiptap/ProseMirror loaded **lazily** from esm.sh (pinned @2.27.2 + tiptap-markdown@0.8.10) via the memoized `window.loadTiptap()` in `template.py`, awaited by `enterEditMode()` (`_editModeLoading` guards double-entry); a load failure still lands on the raw-textarea fallback. Vibrant.js is likewise `loadVibrant()` behind the image-theme command. Extensions: StarterKit, TaskList, TaskItem, Table (row/cell/header), Placeholder, Link (`openOnClick: false`, autolink, linkOnPaste), Image. Link toolbar button + `link` command in `_CMD_MAP` with URL prompt. Markdown configured with `html: false`. Frontmatter stripped before Tiptap (stashed in `_stashedFrontmatter`), prepended on save. Edit mode hides annotations UI and exits diff/home mode on enter. Falls back to raw textarea if CDN unavailable. `body.edit-mode` and `body.edit-dirty` classes control dirty-state indicator (yellow caret, badge border). Editor surface matches read-mode typography (DM Sans body, Cormorant Garamond h1-h2, same `--base-size` and `line-height: 1.65`). Floating pencil button (`#edit-toggle`) mirrors annotations toggle styling with halo-glow hover.
- **Tags**: stored in sidecar JSON `"tags"` array; 7 predefined + 6 prompt tags + custom via palette `#` prefix.

## Server internals and the client–server contract

Transport, polling, change detection, instances, tab lifecycle, sidecar and version-store integrity, PDF export, and the macOS integration. Endpoint schemas are in `api-reference.md`; module roles and data flow in `architecture.md`. Read this before changing anything in `dabarat/*.py`, `polling.js`, `init.js`, or `tabs.js`.

### Storage and config

- **Config dir**: `~/.dabarat/` (versions.db, instances, recent.json, config.json). Legacy git history at `~/.dabarat/history/` auto-imported once on first database creation, then left as read-only archive. Auto-migrates from `~/.mdpreview/` on first run.
- **Config persistence**: `~/.dabarat/config.json` stores cross-window preferences (currently `theme`). Read by `_read_config()`, written atomically by `_write_config()` (tempfile + `os.replace`). Served via `GET /api/config`, updated via `POST /api/config`. Template injects server-side theme into the FOUC-prevention script as a fallback after localStorage.
- Annotations stored in sidecar JSON (`file.md.annotations.json`) — original markdown never modified. Resolved annotations archived to `file.md.annotations.resolved.json`. Bookmarks persist globally to `~/.claude/bookmarks/INDEX.md` + per-snippet files.
- **Orphan cleanup** runs in `GET /api/annotations` **only when `annotations_dirty` is set** on the tab (by `_refresh_tab` on an external change, by save, and by default on a fresh tab so the first fetch after open cleans) — never a sidecar rewrite on an idle poll; annotate/resolve POSTs do not trigger it. Stale anchors removed automatically.
- **Annotation sidecar integrity**: `annotations.write` runs under a per-file `RLock` (`annotations.locked(filepath)`) with tempfile + `os.replace`; a sidecar that fails to parse is moved to `<file>.annotations.json.corrupt-<ts>` and reported once via `pop_corrupt_notice` (never silently overwritten) — but only from tab-scoped reads; listings (`/api/browse-dir`, `recent._count_annotations`) call `annotations.read(path, quarantine=False)` so a directory browse never renames a file another instance may be mid-write on. Any OSError other than missing-file propagates (a read-modify-write that treated EACCES as "empty" would wipe the sidecar). `annotations_dirty` clears only after a successful cleanup whose snapshot `change_key` still matches the live tab. `history.snapshot_external` returns a bool; `_refresh_tab` records a failure as `snapshot_failed` on the tab so the client can warn. Regression: `python3 scripts/verify/phase16_annotation_integrity.py` (V1–V5).
- **Version history**: SQLite-backed at `~/.dabarat/versions.db`—content-addressed zlib blobs, files/file_aliases tables (rename-surviving identity), versions table with source tags (`save`/`restore`/`external`/`import`), pin/label columns. Append-only: no coalescing, no pruning, dedup by hash. Version refs are decimal ids serialized under the legacy `"hash"` field—clients treat them as opaque. `/api/save` snapshots pre-existing disk state (`source='external'`) before overwriting and returns `backedUp: true`; `_refresh_tab` snapshots externally-detected changes via `snapshot_external()`. Endpoints: `GET /api/diff-version` (version-vs-current diff), `POST /api/version/pin`, `POST /api/version/label`, `GET /api/version/summary` (first-hunk changed lines vs predecessor, 5000-line cap). Panel UI conventions are in `ui-chrome.md`.

### Threads, transport, and polling

- **Thread safety**: `_browse_cache` in `server.py` protected by `threading.Lock()`; `frontmatter._fm_cache` is bounded (256, FIFO) under `_fm_cache_lock`; `history._db()` runs `PRAGMA journal_mode=WAL` + the schema script once per process per `DB_PATH` under `_init_lock`. All shared module-level dicts under `ThreadingHTTPServer` require lock protection. `_tabs` access goes through locked helpers — `_tab_filepath()`, `_tab_dirs()`, `_refresh_tab()`, `_update_tab_content()` — never index `self._tabs` directly in handlers.
- **Transport**: `PreviewHandler` speaks HTTP/1.1 with keep-alive (`protocol_version`, `timeout = 30`; the server subclass sets `block_on_close = False` so `server_close()` never joins parked keep-alive threads). Every body goes through `_send_bytes(status, ctype, data, cache_control, etag, extra_headers)` — `Content-Length` always, `Vary: Accept-Encoding`, gzip (`compresslevel=5, mtime=0`) above `_GZIP_MIN_BYTES` when accepted; `/api/preview-image` and the static fallback bypass it (already-compressed bytes). `do_POST` runs `_check_origin` **before** reading the body — a foreign page must never make a handler thread buffer its payload — and the 403 carries `Connection: close` so the unread body cannot be parsed as the next request; `_read_body` answers 413 + close above `_BODY_MAX_BYTES` (10 MB) without reading, 400 + close on negative/chunked/malformed lengths. The shell carries a weak ETag (`W/"sha1[:16]"` of the rendered HTML, `Cache-Control: no-cache`) → 304 on `If-None-Match`; the gzipped shell is memoized per ETag in `_gz_cache` (bounded by `_GZ_CACHE_MAX`). `template._get_bundle()` memoizes the concatenated CSS/JS on `max(st_mtime_ns)` of the module files. `/api/content?since=<changeKey>` answers `{unchanged: true, changeKey, fileMissing?, fileError?}` when nothing moved (200 + JSON, never 304 — a hand-set conditional would break `res.json()`). Regression: `python3 scripts/verify/phase15_transport.py` (V1–V9).
- **Change detection**: `changeKey = f"{st.st_mtime_ns}:{st.st_size}"` is the reload signal (float mtime equality misses sub-second rewrites). `/api/content`, `/api/save`, `/api/restore` return it; client compares/stores `tabs[id].changeKey`. `GET /api/mtime?tab=` is the stat-only probe (edit-mode watch). Edit-mode probe skips when `document.hidden` (prevents false "Server unreachable" banners on sleep/wake); `visibilitychange` listener resets `_editProbeFailures` on page focus. Edit mode also polls `/api/tabs` at `POLL_TABS_MS` interval to detect externally added tabs (via `--add` or instance dialog).
- **Poll cadence**: read mode polls `/api/content` + `/api/annotations` every `POLL_ACTIVE_MS` (500 ms) with `since=`; inactive tabs and `/api/tabs` every `POLL_TABS_MS` (2 s); a hidden window drops to `POLL_HIDDEN_MS` (5 s) and `visibilitychange` clears `_pollTimer` and polls immediately. `_pollInFlight` guards re-entrancy — calling `poll()` without it forks a second chain forever. `init.js` fetches content only for the active tab; inactive tabs get their `changeKey` from `/api/mtime` and lazy-load on first activation (`switchTab`). `tabs[id].loaded` is the truth — every "render if we have the document" fall-through (`closeTab`, `_closeBulk`, the server-removed-active path in `polling.js`, `enterEditMode`) goes through `_tabLoaded(t)` in `state.js` and calls `fetchTabContent` otherwise; a `content`-truthiness check would leave the closed document painted and the `since=` poll would lock it in (review finding, 2026-09-06). Regression: `python3 scripts/verify/phase18_lazy_tabs_highlights.py` (V1–V6: lazy start, overlapping-anchor marks, closeTab/server-close/switchTab successors, edit-mode fetch-first). Classic CDN scripts are pinned (marked@15.0.12, @twemoji/api@17.0.3) with `preconnect`s and Phosphor's two weight stylesheets; they stay parser-blocking because the inline bundle uses `marked` at parse time.
- **Content vs body**: `/api/content` returns `content` (always the raw file — the editor round-trips it) plus `body` (frontmatter-stripped) when fm exists. Render paths use `tabBody(tab)` (`render.js`); never render raw content or frontmatter leaks into the preview, never save the body or frontmatter is destroyed.
- **Browse-dir hot path**: each file under 1MB is read **once**; the text feeds `frontmatter.parse_frontmatter_text` and the `recent._extract_*_text` variants (`_extract_word_count_text`, `_extract_summary_text`, `_extract_preview_text`, `_extract_preview_image(path, text=)`), tags + annotation count come from one `annotations.read`, and version counts from one `history.version_summaries(paths)` query per directory (never a SQLite connection per row). Cache key is the sorted `(name, mtime_ns, size)` tuple (float mtime + count missed same-second and size-only rewrites). Per-file failures aggregate into a `partial` count on the response instead of silent `except: pass`. `/api/content` and `/api/browse-dir` emit a `Server-Timing: total;dur=<ms>` header — DevTools → Network → Timing is the perf signal; sub-ms cached, ~1 ms/file cold.

### Instances and tabs

- **Instance lifecycle**: launching `dabarat file.md` scans ALL live instances via `_live_instances()`. Single instance: enhanced dialog shows open files + Add to Existing / Open New Window / Cancel. Multiple instances: `choose from list` picker shows each window's open files, lets user choose which to add to. "Open New Window" takes a free port (socket bind-0). After adding, Chrome is activated via `_activate_chrome()`. `_kill_port` refuses responsive dabarat instances; only unresponsive zombies are cleared. PID files are JSON `{pid, port, started}` with liveness verified via `/api/tabs` + 30s startup grace.
- **Instance monitoring**: discovery lives in `dabarat/instances.py` (`discover_instances(self_port, self_paths)` — PID scan + sibling probes in a `ThreadPoolExecutor` so N siblings cost one probe timeout, not N; `scan_live` also sweeps `<port>.tabs.json` orphans with no `.pid` older than 7 days; `__main__.py` imports the lifecycle helpers from here and reuses the live list it already has for the `Instance N/max` line — never a second scan). Endpoints: `GET /api/instances` (self tabs from `self._tabs` under lock, never a self-probe), `POST /api/shutdown` (respond, then daemon-thread `server.shutdown()` after ~200ms), `POST /api/instances/shutdown` (server-to-server urllib proxy setting `Origin: http://127.0.0.1:{port}` to pass the sibling's strict `_check_origin` — never relax CSRF/CORS for cross-port calls). UI: `#instance-indicator` in the status bar (`:PORT` + `+N` sibling badge, dropdown with Focus/Shut Down), palette command "Instances", fetch on init + 45s interval — never on the 2s poll.
- **Tab-session persistence**: `~/.dabarat/instances/<port>.tabs.json` (atomic write via `_on_tabs_changed` hook on add/close/rename), cleared on clean exit, restored by `dabarat --port <port>` with no file args after an unclean death. **Restore-session prompt**: crash recovery of >20 tabs asks via AppleScript (Restore / Start Fresh); Start Fresh discards the state file. Headless/AppleScript-unavailable restores silently.
- **Ghost tabs**: deleted/moved files serve cached content with `fileMissing: true`; the tab name dims with strikethrough (`.tab.ghost`) and a `.status-banner` appears; saving recreates the file. Save conflicts: client sends `baseChangeKey`, server 409s if the disk changed, client confirms overwrite.
- **Tab bulk close**: `POST /api/close-bulk` (`mode: all|others|ids`) holds `_tabs_lock` once and fires `_notify_tabs_changed()` once per batch. Client `_closeBulk` confirms when closing >1, exits edit/diff/version modes referencing doomed tabs first, deletes client state synchronously before the POST, and adds ids to the `_closePending` set (released 2.5s after the POST) — both `/api/tabs` re-add sites in `polling.js` check it so an in-flight poll response can't resurrect a closed tab. Also: middle-click close (`auxclick`), Ctrl+Tab / Ctrl+Shift+Tab cycling (input/contenteditable-guarded), context-menu Close Others/All, overflow menu with autofocused filter + per-row close. Regression: `python3 scripts/verify/phase12_instances_tabs.py` (V1–V12: discovery shape, batch semantics + single tabs.json write, proxy/self shutdown, CDP cycling + overflow).
- **Auto-tab cap**: `POST /api/add` accepts `auto: true` (sent by `~/.claude/hooks/dabarat-open.py`, which fires only for `~/.claude/plans/*.md`). Auto tabs are capped at `MAX_AUTO_TABS` (`server.py`, env `DABARAT_MAX_AUTO_TABS`, default 30) — oldest auto tab evicted on insert; user-opened tabs are never counted or evicted; a save via `_update_tab_content` clears the flag (the user has claimed it). Born of a 103-tab window that accreted over 16 days from the old project-dir hook trigger — never re-widen the hook without this cap. `_closeBulk` snapshots client state and restores it on a non-OK response (a stale pre-Aug-19 server 404s the endpoint) with a `_showServerActionFailedBanner` — without that the 2s poll silently resurrects every tab and the action reads as a no-op. `/api/preview-image` allowlist = open-tab dirs + browse-cache dirs + **recent-file dirs** (home cards reference closed tabs). Regression: `python3 scripts/verify/phase14_auto_tabs_preview.py` (V1–V6).

### Export and macOS

- **PDF export**: `pdf_export.py` uses headless Chrome CDP with zero page margins (`@page { margin: 0 }`, CDP margins: 0). Visual spacing via `#content { padding: 0.6in }` in print mode. Export mode: `?theme=X&export=1` skips polling + emits render-complete sentinel. `print-color-adjust: exact` preserves dark backgrounds. `html` gets theme background in print to prevent outline artifacts on dark themes. Latte/Dawn/Tokyo Light override `html` and `body` to `#fff` via `html[data-theme="…"]` (the attribute lives on `<html>`, so a descendant `[data-theme] html` selector never matches); Vellum prints on its own `--ctp-base` (its card note says "NOT pure white" and print agrees). Browser print keeps `@page { margin: 0.5in 0 }` (documented inline — the zero-margin contract is the CDP export path); `thead { position: static }` in print so repeated headers work. Export passes `?date=<ISO>` and `init.js` renders the `.pdf-date` stamp.
- **PDF figures (Pandoc convention)**: `![fig](tree.pdf){width=100%}` is a LaTeX-pipeline idiom — browsers cannot decode PDF in `<img>`. `recent.browser_image_path()` maps `.pdf`/`.eps` refs to a same-stem `.svg`/`.png`/`.jpg`/`.webp` sibling; applied in `_extract_preview_image` (home cards) and in the relative-static fallback in `server.py` **only when `Sec-Fetch-Dest: image`** (so `[link](doc.pdf)` still opens the PDF). `render.js` strips the trailing `{…}` attribute block before `marked.parse`. Never edit the source markdown to "fix" this — the PDF is what the paper's build wants. Regression: phase14 V7a–c.
- **Finder integration (macOS)**: `Dabarat.app` droplet at `~/Applications/`. Bundle ID: `com.minoanmystery.dabarat`. Rebuild after Python upgrade: `bash macos/build.sh`. Default handler: `duti -s com.minoanmystery.dabarat .md all`.

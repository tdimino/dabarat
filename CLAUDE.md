# Markdown Dabarat

Zero-dependency Python markdown previewer with annotations, bookmarks, and live reload.

Part of the [Claudius](https://github.com/tdimino/claudius) ecosystem.

## Stack
- Python 3.10+ (stdlib only — no pip dependencies)
- CDN: marked.js, marked-footnote, highlight.js, Phosphor Icons, Twemoji, Vibrant.js, Motion One, Tiptap/ProseMirror (cached after first load)
- 8 themes: 4 dark (Ink, Mocha, Rosé Pine, Tokyo Storm) + 4 light (Vellum, Latte, Rosé Pine Dawn, Tokyo Light). Ink + Vellum are The Scholar's Codex pair — parchment-and-iron-gall register with tungsten gold and rubricated red-ochre signature accents.

## Structure
- 12 Python modules in `dabarat/` — `server.py` (HTTP + 50 endpoints), `template.py` (HTML assembly), `annotations.py`, `bookmarks.py`, `frontmatter.py`, `diff.py`, `history.py`, `recent.py`, `workspace.py`, `pdf_export.py`, `instances.py` (instance discovery), `__main__.py` (CLI entry)
- 16 JS modules in `static/js/` concatenated in dependency order — see `agent_docs/client-architecture.md`
- 14 CSS modules in `static/css/` concatenated in dependency order — theme-variables, base-layout, typography, then feature-specific (annotations, editor, diff, home, etc.)
- `static/palette.js` — Command palette + tag mode (Cmd+K) — loaded separately
- `macos/` — Finder integration: `build.sh` builds `Dabarat.app` droplet, `Info.plist` declares UTIs (`com.minoanmystery.dabarat`)

## Install
- `pip install .` from project root — installs `dabarat`, `dbrt`, `mdpreview`, and `mdp` globally (non-editable required for Finder "Open With" — editable installs hit macOS TCC on `~/Desktop/`)
- `pip install -e .` for development — changes take effect immediately but Finder integration won't work (TCC blocks `~/Desktop/` access from AppleScript droplets)

## Commands
- Run: `dabarat document.md` (or `dbrt`, `mdpreview`, `mdp`, `python3 -m dabarat`)
- Workspace: `dabarat --workspace research.dabarat-workspace`
- Add tab: `dabarat --add another.md`
- Export PDF: `dabarat --export-pdf file.md [-o output.pdf] [--theme mocha]`
- CLI annotate: `dabarat --annotate file.md --text "passage" --comment "note" --type suggestion`

## Conventions
- Annotations stored in sidecar JSON (`file.md.annotations.json`) — original markdown never modified
- Resolved annotations archived to `file.md.annotations.resolved.json`
- Bookmarks persist globally to `~/.claude/bookmarks/INDEX.md` + per-snippet files
- Default port: 3031, default author: "Tom"
- Orphan cleanup runs in `GET /api/annotations` **only when `annotations_dirty` is set** on the tab (by `_refresh_tab` on an external change, by save, and by default on a fresh tab so the first fetch after open cleans) — never a sidecar rewrite on an idle poll; annotate/resolve POSTs do not trigger it. Stale anchors removed automatically.
- Tags stored in sidecar JSON `"tags"` array; 7 predefined + 6 prompt tags + custom via palette `#` prefix
- `.prompt.md` files auto-detect YAML frontmatter → indicator bar + click-to-open metadata popup
- `{{variable}}` and `${variable}` template slots highlighted as colored pills with schema tooltips
- Blockquotes: no italic (matches GitHub/VS Code/Typora convention) — `em` and `code` inside blockquotes reset to `font-style: normal` to prevent Victor Mono cursive rendering
- Emoji style: 4 options (Twemoji, OpenMoji, Noto, Native) via `EMOJI_CDNS` in `theme.js`. `applyEmojiStyle()` runs after `marked.parse()`
- **Config dir**: `~/.dabarat/` (versions.db, instances, recent.json, config.json). Legacy git history at `~/.dabarat/history/` auto-imported once on first database creation, then left as read-only archive. Auto-migrates from `~/.mdpreview/` on first run.
- **Config persistence**: `~/.dabarat/config.json` stores cross-window preferences (currently `theme`). Read by `_read_config()`, written atomically by `_write_config()` (tempfile + `os.replace`). Served via `GET /api/config`, updated via `POST /api/config`. Template injects server-side theme into the FOUC-prevention script as a fallback after localStorage.
- **localStorage prefix**: `dabarat-*` keys. Migration IIFE in `state.js` copies `mdpreview-*` → `dabarat-*` on first load.
- **Color convention**: Never use hardcoded rgba channel values—use `rgba(var(--ctp-*-rgb), alpha)` from `theme-variables.css`. RGB companions (`--ctp-yellow-rgb`, `--ctp-blue-rgb`, etc.) auto-switch per theme. Latte overrides only needed when alpha values differ from Mocha defaults. TAG_COLORS in `palette.js` uses the `--badge-<hue>-fg` role tokens for text and CSS variable references for washes. Shadows are the one sanctioned neutral: `--elevation-1`/`--elevation-2` in `theme-variables.css` own every `rgba(0,0,0,…)`; modules consume the tokens (tinted accent glows stay `rgba(var(--ctp-*-rgb), α)`). `audit.py` (`hardcoded_rgba_findings`, `undefined_var_findings`) and `scripts/verify/phase17_tokens.py` fail on hex/named colors and non-neutral rgba literals outside `theme-variables.css` and on any `var(--x)` that doesn't resolve in every theme; neutral washes (`rgba(0,0,0|255,255,255|128,128,128, α)`) stay allowed as borders/washes, and only neutral *box-shadows* are policed (phase17 V1). Theme swatches (`themeSwatches()` in `palette.js`) and surface probes (`_themeVar`/`_themeSurfaceRgb` in `theme.js`) are read from computed style — there is no hand-copied palette table to keep in sync.
- **Whisper tier (contrast waiver)**: document-view `--ctp-overlay1` text (figcaptions, footnote backrefs, list markers) and the TOC section kicker (`--ctp-overlay0` on mantle) are deliberately de-emphasized and waived from WCAG AA by decision — do not "fix" it to 4.5:1. On the home screen the waiver covers ONLY hover-revealed ghost controls (`.home-card-remove`, `.ws-section-remove`, `.ws-entry-remove`, `.home-section-remove`, `.home-quote-refresh`); all other home text passes 4.5:1 via the home role tokens ("everything readable" decision, 2026-08-19). `scripts/color-audit/audit.py` tracks waived rows in a separate `waived` section; everything else must pass its tier, and the script exits 1 on any P0.
- **Color-role tokens**: Elements whose raw accent can fail contrast on its real surface consume role tokens, not accents: `--hljs-*` (syntax, on mantle), `--tpl-pill-mustache`/`--tpl-pill-dollar` (over their washes), `--h3/h4/h5-color` (on base), `--link-visited`, `--stat-add`/`--stat-del`, `--external-badge-fg` (on **crust**, its real surface), `--toc-link` (on mantle), the home tokens `--home-meta`/`--home-control`/`--home-icon` (base + card + **crust** — the status bar consumes them too, "status bar readable" decision 2026-09-06), and `--badge-<hue>-fg` (badge/tag text over its wash on card, base, and surface0 — the worst surface wins). h3–h5 audit at 4.5:1 (they render below the 18.66px large-text bar at every allowed `--base-size`); only h1/h2 get 3:1. Ink and Vellum keep h3 as the single rubric accent and set `--h4-color`/`--h5-color` to `--ctp-text` (tonal tiers, structure through weight/small-caps — a `/* pair-scoped */` comment marks those Ink+Vellum-only groups so `override_findings` skips them). Defaults alias the accents in `:root`; themes override only failing slots with concrete hexes in `theme-variables.css` — mocha's own overrides live in a standalone `[data-theme="mocha"]` block right after `:root` (concrete values in `:root` would leak into every theme). New color+surface pairs must be registered in `USED_PAIRS` in `audit.py`; `scripts/color-audit/solve.py` proposes passing values (hue held, lightness walked) for any row that fails. For a token used on two surfaces, adopt the worse-surface solution (card for dark themes, base for light).
- **Attention-hue convention**: yellow marks pending user work (unsaved/dirty state — caret, badge); peach marks provenance/awareness (external-change badge, unseen-activity dots). The split is deliberate severity semantics, not drift — don't unify them.
- **Vellum shadow exception**: Vellum uses warm umber shadows (`rgba(70, 48, 20, ...)`) instead of the neutral `rgba(0, 0, 0, ...)` used by every other theme. Pure-black shadows punch cold holes into its warm parchment base; the convention break is documented inline in `theme-variables.css` and should not be "normalized" back.
- **Interactive token convention**: For hover/focus states on surfaces that use `--card-bg` (white in light themes), use `var(--interactive-hover-bg)` (dark: `--ctp-surface1`, light: `--ctp-crust`) and `var(--interactive-muted-bg)` (dark: `rgba(surface1, 0.85)`, light: `rgba(0,0,0,0.06)`) instead of raw `var(--ctp-surface1)` which is invisible on white.
- **Event delegation**: Never use inline `onclick` handlers in dynamically-built HTML—use `data-*` attributes + `addEventListener` event delegation. This prevents XSS via HTML entity decoding in path strings.
- **Menu keyboard model**: `_menuKeyNav(menu, itemSelector)` in `tabs.js` gives the `.tab-context-menu` family `role="menu"` + `menuitem` rows (`tabindex="-1"`) with ArrowUp/Down traversal and Enter activation; the context menu focuses its first row on open. The instance dropdown is `role="dialog"` instead—its rows hold real buttons, so Tab traverses natively. Any new dropdown reuses `_menuKeyNav`, and any hover-revealed control (overflow close ×, float-button labels, home ghosts) must pair a `:focus-within`/`:focus-visible` reveal so keyboard focus is never invisible.
- **Motion One**: Optional animation CDN loaded as ES module (`@motionone/dom`). Assigns `window.Motion` with `animate`, `stagger`, `spring`. All call sites MUST guard with `if (window.Motion && !_prefersReducedMotion)` for progressive enhancement + accessibility. `_prefersReducedMotion` is a `let` in `state.js` kept live by a `matchMedia('(prefers-reduced-motion: reduce)')` change listener. Falls back to CSS `@keyframes` animations. See `@agent_docs/motion-one.md` for full call site reference.
- **Image lightbox**: Content images (excluding `.emoji` and `.tpl-var-img`) get `cursor: zoom-in` and open lightbox on click
- **Workspace system**: See `@agent_docs/workspace-system.md` for full internals. Key state: server-side `_active_workspace`/`_active_workspace_path`, client-side in `state.js`
- **PDF export**: `pdf_export.py` uses headless Chrome CDP with zero page margins (`@page { margin: 0 }`, CDP margins: 0). Visual spacing via `#content { padding: 0.6in }` in print mode. Export mode: `?theme=X&export=1` skips polling + emits render-complete sentinel. `print-color-adjust: exact` preserves dark backgrounds. `html` gets theme background in print to prevent outline artifacts on dark themes. Latte/Dawn/Tokyo Light override `html` and `body` to `#fff` via `html[data-theme="…"]` (the attribute lives on `<html>`, so a descendant `[data-theme] html` selector never matches); Vellum prints on its own `--ctp-base` (its card note says "NOT pure white" and print agrees). Browser print keeps `@page { margin: 0.5in 0 }` (documented inline — the zero-margin contract is the CDP export path); `thead { position: static }` in print so repeated headers work. Export passes `?date=<ISO>` and `init.js` renders the `.pdf-date` stamp.
- **Finder integration (macOS)**: `Dabarat.app` droplet at `~/Applications/`. Bundle ID: `com.minoanmystery.dabarat`. Rebuild after Python upgrade: `bash macos/build.sh`. Default handler: `duti -s com.minoanmystery.dabarat .md all`
- **Thread safety**: `_browse_cache` in `server.py` protected by `threading.Lock()`; `frontmatter._fm_cache` is bounded (256, FIFO) under `_fm_cache_lock`; `history._db()` runs `PRAGMA journal_mode=WAL` + the schema script once per process per `DB_PATH` under `_init_lock`. All shared module-level dicts under `ThreadingHTTPServer` require lock protection. `_tabs` access goes through locked helpers — `_tab_filepath()`, `_tab_dirs()`, `_refresh_tab()`, `_update_tab_content()` — never index `self._tabs` directly in handlers.
- **Change detection**: `changeKey = f"{st.st_mtime_ns}:{st.st_size}"` is the reload signal (float mtime equality misses sub-second rewrites). `/api/content`, `/api/save`, `/api/restore` return it; client compares/stores `tabs[id].changeKey`. `GET /api/mtime?tab=` is the stat-only probe (edit-mode watch). Edit-mode probe skips when `document.hidden` (prevents false "Server unreachable" banners on sleep/wake); `visibilitychange` listener resets `_editProbeFailures` on page focus. Edit mode also polls `/api/tabs` at `POLL_TABS_MS` interval to detect externally added tabs (via `--add` or instance dialog).
- **Content vs body**: `/api/content` returns `content` (always the raw file — the editor round-trips it) plus `body` (frontmatter-stripped) when fm exists. Render paths use `tabBody(tab)` (`render.js`); never render raw content or frontmatter leaks into the preview, never save the body or frontmatter is destroyed.
- **Instance lifecycle**: launching `dabarat file.md` scans ALL live instances via `_live_instances()`. Single instance: enhanced dialog shows open files + Add to Existing / Open New Window / Cancel. Multiple instances: `choose from list` picker shows each window's open files, lets user choose which to add to. "Open New Window" takes a free port (socket bind-0). After adding, Chrome is activated via `_activate_chrome()`. `_kill_port` refuses responsive dabarat instances; only unresponsive zombies are cleared. PID files are JSON `{pid, port, started}` with liveness verified via `/api/tabs` + 30s startup grace.
- **Instance monitoring**: discovery lives in `dabarat/instances.py` (`discover_instances(self_port, self_paths)` — PID scan + sibling probes in a `ThreadPoolExecutor` so N siblings cost one probe timeout, not N; `scan_live` also sweeps `<port>.tabs.json` orphans with no `.pid` older than 7 days; `__main__.py` imports the lifecycle helpers from here and reuses the live list it already has for the `Instance N/max` line — never a second scan). Endpoints: `GET /api/instances` (self tabs from `self._tabs` under lock, never a self-probe), `POST /api/shutdown` (respond, then daemon-thread `server.shutdown()` after ~200ms), `POST /api/instances/shutdown` (server-to-server urllib proxy setting `Origin: http://127.0.0.1:{port}` to pass the sibling's strict `_check_origin` — never relax CSRF/CORS for cross-port calls). UI: `#instance-indicator` in the status bar (`:PORT` + `+N` sibling badge, dropdown with Focus/Shut Down), palette command "Instances", fetch on init + 45s interval — never on the 2s poll.
- **Tab bulk close**: `POST /api/close-bulk` (`mode: all|others|ids`) holds `_tabs_lock` once and fires `_notify_tabs_changed()` once per batch. Client `_closeBulk` confirms when closing >1, exits edit/diff/version modes referencing doomed tabs first, deletes client state synchronously before the POST, and adds ids to the `_closePending` set (released 2.5s after the POST) — both `/api/tabs` re-add sites in `polling.js` check it so an in-flight poll response can't resurrect a closed tab. Also: middle-click close (`auxclick`), Ctrl+Tab / Ctrl+Shift+Tab cycling (input/contenteditable-guarded), context-menu Close Others/All, overflow menu with autofocused filter + per-row close. Regression: `python3 scripts/verify/phase12_instances_tabs.py` (V1–V12: discovery shape, batch semantics + single tabs.json write, proxy/self shutdown, CDP cycling + overflow).
- **Auto-tab cap**: `POST /api/add` accepts `auto: true` (sent by `~/.claude/hooks/dabarat-open.py`, which fires only for `~/.claude/plans/*.md`). Auto tabs are capped at `MAX_AUTO_TABS` (`server.py`, env `DABARAT_MAX_AUTO_TABS`, default 30) — oldest auto tab evicted on insert; user-opened tabs are never counted or evicted; a save via `_update_tab_content` clears the flag (the user has claimed it). Born of a 103-tab window that accreted over 16 days from the old project-dir hook trigger — never re-widen the hook without this cap. `_closeBulk` snapshots client state and restores it on a non-OK response (a stale pre-Aug-19 server 404s the endpoint) with a `_showServerActionFailedBanner` — without that the 2s poll silently resurrects every tab and the action reads as a no-op. `/api/preview-image` allowlist = open-tab dirs + browse-cache dirs + **recent-file dirs** (home cards reference closed tabs). Regression: `python3 scripts/verify/phase14_auto_tabs_preview.py` (V1–V6).
- **PDF figures (Pandoc convention)**: `![fig](tree.pdf){width=100%}` is a LaTeX-pipeline idiom — browsers cannot decode PDF in `<img>`. `recent.browser_image_path()` maps `.pdf`/`.eps` refs to a same-stem `.svg`/`.png`/`.jpg`/`.webp` sibling; applied in `_extract_preview_image` (home cards) and in the relative-static fallback in `server.py` **only when `Sec-Fetch-Dest: image`** (so `[link](doc.pdf)` still opens the PDF). `render.js` strips the trailing `{…}` attribute block before `marked.parse`. Never edit the source markdown to "fix" this — the PDF is what the paper's build wants. Regression: phase14 V7a–c.
- **Frontmatter modal**: `.fm-popup-backdrop` is `align-items: center` (true centre, never top-anchored). Fields without a dedicated renderer go through `_fmFieldGrid()` (`frontmatter.js`) — a `<dl class="fm-popup-fields">` grid: keys in `--hljs-keyword`, string values in `--ctp-text`, numbers/booleans in `--hljs-number`, URLs as links in `--hljs-function`, scalar arrays as `.pmc-label` pills, plain objects as a nested inset grid (depth ≤ 2, keys in `--hljs-params`), anything else as `.fm-popup-raw` JSON. textContent only — never innerHTML with frontmatter values. Version-timeline rows hover with `--interactive-muted-bg` (tint), not `--ctp-surface0` (cold slab on Vellum); `.version-btn` sits on `--card-bg` at subtext tier.
- **Restore-session prompt**: crash recovery of >20 tabs asks via AppleScript (Restore / Start Fresh); Start Fresh discards the state file. Headless/AppleScript-unavailable restores silently.
- **Tab-session persistence**: `~/.dabarat/instances/<port>.tabs.json` (atomic write via `_on_tabs_changed` hook on add/close/rename), cleared on clean exit, restored by `dabarat --port <port>` with no file args after an unclean death.
- **Ghost tabs**: deleted/moved files serve cached content with `fileMissing: true`; the tab name dims with strikethrough (`.tab.ghost`) and a `.status-banner` appears; saving recreates the file. Save conflicts: client sends `baseChangeKey`, server 409s if the disk changed, client confirms overwrite.
- **Browse-dir hot path**: each file under 1MB is read **once**; the text feeds `frontmatter.parse_frontmatter_text` and the `recent._extract_*_text` variants (`_extract_word_count_text`, `_extract_summary_text`, `_extract_preview_text`, `_extract_preview_image(path, text=)`), tags + annotation count come from one `annotations.read`, and version counts from one `history.version_summaries(paths)` query per directory (never a SQLite connection per row). Cache key is the sorted `(name, mtime_ns, size)` tuple (float mtime + count missed same-second and size-only rewrites). Per-file failures aggregate into a `partial` count on the response instead of silent `except: pass`. `/api/content` and `/api/browse-dir` emit a `Server-Timing: total;dur=<ms>` header — DevTools → Network → Timing is the perf signal; sub-ms cached, ~1 ms/file cold.
- **WYSIWYG editing**: Tiptap/ProseMirror loaded **lazily** from esm.sh (pinned @2.27.2 + tiptap-markdown@0.8.10) via the memoized `window.loadTiptap()` in `template.py`, awaited by `enterEditMode()` (`_editModeLoading` guards double-entry); a load failure still lands on the raw-textarea fallback. Vibrant.js is likewise `loadVibrant()` behind the image-theme command. Extensions: StarterKit, TaskList, TaskItem, Table (row/cell/header), Placeholder, Link (`openOnClick: false`, autolink, linkOnPaste), Image. Link toolbar button + `link` command in `_CMD_MAP` with URL prompt. Markdown configured with `html: false`. Frontmatter stripped before Tiptap (stashed in `_stashedFrontmatter`), prepended on save. Edit mode hides annotations UI and exits diff/home mode on enter. Falls back to raw textarea if CDN unavailable. `body.edit-mode` and `body.edit-dirty` classes control dirty-state indicator (yellow caret, badge border). Editor surface matches read-mode typography (DM Sans body, Cormorant Garamond h1-h2, same `--base-size` and `line-height: 1.65`). Floating pencil button (`#edit-toggle`) mirrors annotations toggle styling with halo-glow hover.
- **Light-theme override convention**: All four light themes (Latte, Vellum, Rosé Pine Dawn, Tokyo Light) MUST appear together in every `[data-theme="..."]` override block across all CSS files (`editor.css`, `annotations.css`, `base-layout.css`, etc.). Omitting any light theme from a selector group causes silent contrast/styling regressions on that theme.
- **Floating button hover pattern**: `#annotations-toggle`, `#edit-toggle`, `#history-toggle`, and `#toc-restore` use halo-glow hover (accent border + ring shadow + diffuse glow + `scale(1.08)`) rather than solid background fill. All four are glassmorphic circles with `backdrop-filter: blur(8px)` behind `@supports`, positioned at `top: 46px` / `top: 86px` / `top: 126px` (right side) and `top: 46px` (left side) to clear the tab bar. `#history-toggle` hidden in edit/diff/print modes. `scale(0.96)` active state for tactile feedback.
- **Toolbar hover pattern**: Formatting buttons (`.edit-fmt-btn`) use micro-glow hover (accent border + 1px ring shadow + 6px diffuse glow + 2px inset bottom accent indicator). Active (toggled-on) buttons retain the bottom indicator permanently. Save and Close buttons use outline hover (accent border + text color, no background fill). Dirty-state save button on light themes uses `--ctp-text` instead of `--ctp-yellow` for readability.
- **Version history**: SQLite-backed at `~/.dabarat/versions.db`—content-addressed zlib blobs, files/file_aliases tables (rename-surviving identity), versions table with source tags (`save`/`restore`/`external`/`import`), pin/label columns. Append-only: no coalescing, no pruning, dedup by hash. Version refs are decimal ids serialized under the legacy `"hash"` field—clients treat them as opaque. `/api/save` snapshots pre-existing disk state (`source='external'`) before overwriting and returns `backedUp: true`; `_refresh_tab` snapshots externally-detected changes via `snapshot_external()`. New endpoints: `GET /api/diff-version` (version-vs-current diff), `POST /api/version/pin`, `POST /api/version/label`. UI: palette command "Version History", `Cmd+Shift+H`, floating `#history-toggle` button. Timeline has day separators, source badges, pin/label actions, count badge, delegated event handling. `enterVersionDiffMode` in `diff.js` diffs against the historical version. Panel identity: header shows a mode icon (`ph-clock-counter-clockwise` file / `ph-pulse` Activity) + `#version-panel-filename`; global rows carry a dimmed parent-dir suffix. Change excerpts: per-row caret expander lazily fetches `GET /api/version/summary` (`history.version_change_summary()` — first-hunk changed lines vs predecessor, 5000-line cap); client caches successes only on `_versionsByRef` (`'loading'` sentinel, delete-on-failure keeps retries possible, `entry.isConnected` guard after await). All four floating toggles carry expand-on-hover `.float-btn-label` pills (Edit / History / Notes / Justify) — shared CSS at the END of `history-ui.css` so it wins cascade ties. Regression: `python3 scripts/verify/phase13_history_clarity.py` (V1–V6: excerpt contract, error codes, panel wiring).
- **TOC navigation**: JS-driven, never native hash navigation (browsers only scroll on hash *change* — same-hash re-clicks would be silent no-ops). Delegated click handler on `#toc-list` (rebound by `_tocBoundList` node identity since home mode destroys/restores the node), generation-counted jumps (`_tocActiveJump`), `history.replaceState` hash sync with `{targetId, tabId}` ownership, stale-hash clearing on tab switch, jump re-resolution across polling re-renders. `--toc-heading-offset` (typography.css, 80px on `#content`) is the single source for the JS jump offset, heading `scroll-margin-top`, and the scroll-spy threshold (+2px landing epsilon). `scrollIntoView` is BANNED in render.js — it can cancel the window's in-flight smooth scroll; sidebar centering uses `centerTocLink()` (`#toc-scroll.scrollTo` only). Regression: `python3 scripts/verify/phase7_toc_navigation.py` (V1–V20 CDP matrix), `phase8_editor_roundtrip.py` (V1–V9 link/image/footnote round-trip), `phase9_save_path.py` (V1–V8 save-path integrity), `phase10_sqlite_store.py` (V1–V10 store semantics + git import). ExecPlan: `agent_docs/toc-navigation-execplan.md`.
- **TOC sidebar toggle**: `Cmd+\` keyboard shortcut (also in command palette). Collapse state persists to `localStorage` key `dabarat-toc-collapsed`. `#toc-restore` button bounces in with spring animation (`tocRestoreBounce` keyframe, optional Motion One spring override). JS `matchMedia` listener at 900px fires `toggleToc()` for smooth CSS transitions instead of hard media-query snap; auto-collapse does NOT persist to localStorage (preserves user intent). Content auto-centers when TOC is collapsed (`#content { margin: auto }` globally, `#main-area` margins zeroed).
- **Transport**: `PreviewHandler` speaks HTTP/1.1 with keep-alive (`protocol_version`, `timeout = 30`; the server subclass sets `block_on_close = False` so `server_close()` never joins parked keep-alive threads). Every body goes through `_send_bytes(status, ctype, data, cache_control, etag, extra_headers)` — `Content-Length` always, `Vary: Accept-Encoding`, gzip (`compresslevel=5, mtime=0`) above `_GZIP_MIN_BYTES` when accepted; `/api/preview-image` and the static fallback bypass it (already-compressed bytes). `do_POST` runs `_check_origin` **before** reading the body — a foreign page must never make a handler thread buffer its payload — and the 403 carries `Connection: close` so the unread body cannot be parsed as the next request; `_read_body` answers 413 + close above `_BODY_MAX_BYTES` (10 MB) without reading, 400 + close on negative/chunked/malformed lengths. The shell carries a weak ETag (`W/"sha1[:16]"` of the rendered HTML, `Cache-Control: no-cache`) → 304 on `If-None-Match`; the gzipped shell is memoized per ETag in `_gz_cache` (bounded by `_GZ_CACHE_MAX`). `template._get_bundle()` memoizes the concatenated CSS/JS on `max(st_mtime_ns)` of the module files. `/api/content?since=<changeKey>` answers `{unchanged: true, changeKey, fileMissing?, fileError?}` when nothing moved (200 + JSON, never 304 — a hand-set conditional would break `res.json()`). Regression: `python3 scripts/verify/phase15_transport.py` (V1–V9).
- **Poll cadence**: read mode polls `/api/content` + `/api/annotations` every `POLL_ACTIVE_MS` (500 ms) with `since=`; inactive tabs and `/api/tabs` every `POLL_TABS_MS` (2 s); a hidden window drops to `POLL_HIDDEN_MS` (5 s) and `visibilitychange` clears `_pollTimer` and polls immediately. `_pollInFlight` guards re-entrancy — calling `poll()` without it forks a second chain forever. `init.js` fetches content only for the active tab; inactive tabs get their `changeKey` from `/api/mtime` and lazy-load on first activation (`switchTab`). `tabs[id].loaded` is the truth — every "render if we have the document" fall-through (`closeTab`, `_closeBulk`, the server-removed-active path in `polling.js`, `enterEditMode`) goes through `_tabLoaded(t)` in `state.js` and calls `fetchTabContent` otherwise; a `content`-truthiness check would leave the closed document painted and the `since=` poll would lock it in (review finding, 2026-09-06). Regression: `python3 scripts/verify/phase18_lazy_tabs_highlights.py` (V1–V6: lazy start, overlapping-anchor marks, closeTab/server-close/switchTab successors, edit-mode fetch-first). Classic CDN scripts are pinned (marked@15.0.12, @twemoji/api@17.0.3) with `preconnect`s and Phosphor's two weight stylesheets; they stay parser-blocking because the inline bundle uses `marked` at parse time.
- **Design tokens** (`theme-variables.css` `:root`, guarded by `scripts/verify/phase17_tokens.py`): `--radius-xs/sm/md/lg/xl/2xl/pill`, `--z-toc/panel/float/status/menu/banner/palette/modal/lightbox/overlay`, `--dur-fast/base/mid/slow/slower`, `--ease-standard/out-back/out-expo`, `--elevation-1/2`, `--font-sans/serif/mono`, `--measure` (900px prose column shared by read/edit/frontmatter/variables). Modules never write a px radius, a z-index ≥ 10, a `transition` with a literal duration or `all`, or a neutral rgba shadow; local stacking z-indexes 0–5 are fine. `.btn` in `base-layout.css` is the secondary-pill recipe (DM Sans 11px, `--home-control`, `--ctp-surface1` border, `--interactive-muted-bg` hover, blue `:focus-visible` ring, `scale(.96)` active, `:disabled` at .55) — `.home-action-btn`, `.ws-btn`, `.home-open-btn`, `.version-btn`, instance-row buttons, banner buttons, and the editor Save/Discard pair are deltas on it (history-ui's border-only hover rationale survives as a delta rule). `accent-color: var(--ctp-blue)` and `scrollbar-color` per mode sit on `:root`.
- **Status banners**: one factory — `_showStatusBanner(id, message, severity, {actions, icon, timeout, dismiss})` in `tabs.js` — sets `role="status"` + `aria-live="polite"` (or `role="alert"` + `assertive` for `error`) and `data-severity="info|warn|error"` (blue / yellow / red per the attention-hue convention). `home.js` and `editor.js` never hand-build a `.status-banner`. Server-side signals that surface through it: `snapshotFailed` on `/api/content` (external change not versioned — reported once per failure, then cleared; rides along on the `since=` short form too) and `corruptBackup` on `/api/annotations` (sidecar quarantined).
- **Dialogs and focus**: `openDialog(el, {modal, initialFocus, returnTo})` in `utils.js` backs the palette and the lightbox; the frontmatter popup and the instance menu implement the same contract by hand (focus in on open, back to the opener on dismiss, Tab trapped when modal). The tab strip is a `role="tablist"` of `<div role="tab">` elements with roving tabindex (ArrowLeft/Right, Home/End move focus without activating; Enter/Space activate; Delete/Backspace close the focused tab; `aria-selected`/`aria-controls`) and separate close buttons; the instance menu is non-modal and returns focus to the indicator on Escape/close-button but deliberately NOT on an outside click (the click's target takes focus); `#main-area`/`#content` are `<main>`/`<article>`, the annotation gutter is `<aside>`, the theme toggle has an accessible name.
- **Annotation sidecar integrity**: `annotations.write` runs under a per-file `RLock` (`annotations.locked(filepath)`) with tempfile + `os.replace`; a sidecar that fails to parse is moved to `<file>.annotations.json.corrupt-<ts>` and reported once via `pop_corrupt_notice` (never silently overwritten) — but only from tab-scoped reads; listings (`/api/browse-dir`, `recent._count_annotations`) call `annotations.read(path, quarantine=False)` so a directory browse never renames a file another instance may be mid-write on. Any OSError other than missing-file propagates (a read-modify-write that treated EACCES as "empty" would wipe the sidecar). `annotations_dirty` clears only after a successful cleanup whose snapshot `change_key` still matches the live tab. `history.snapshot_external` returns a bool; `_refresh_tab` records a failure as `snapshot_failed` on the tab so the client can warn. Regression: `python3 scripts/verify/phase16_annotation_integrity.py` (V1–V5).
- **Typography parity**: prose rules in `typography.css` are global (`h1`…`h6`, `p`, `pre code`, `table`), so `.ProseMirror` inherits them and `editor.css` carries only editor chrome — never restate a heading color/size there (phase17 V9). Scale is em-based off `--base-size` (`pre code` 0.82em, `table` 0.88em, footnotes 0.875em); `hr` is a 40% centered `--ctp-surface1` rule; `text-wrap: balance` on display headings, `pretty` on paragraphs, `tabular-nums` on stats/dates. Hebrew webfonts load on demand — `ensureHebrewFonts(md)` in `render.js` injects the `<link id="dabarat-hebrew-fonts">` on the first `/[\u0590-\u05FF]/` match and `init.js` awaits `document.fonts.load` before the export sentinel.
- **Footnotes**: `marked-footnote@1.4.0` UMD loaded after marked.js, registered via `marked.use(markedFootnote())` in `render.js`. Styles in `typography.css` (`section.footnotes`). Editor save path in `editor.js` post-processes serialized markdown to unescape `\[^...\]` → `[^...]` since tiptap-markdown doesn't understand footnote syntax.
